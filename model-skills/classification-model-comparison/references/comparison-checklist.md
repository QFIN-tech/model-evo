# 模型对比评估质量 Checklist

对比完成后逐项检查。

---

## 对齐检查

- [ ] 两个模型的目标定义（Y=1含义）一致
- [ ] 对比的客群维度对齐（V2独有 / V3新增 / 共有）
- [ ] 对比的业务指标口径一致
- [ ] 样本量差异已标注（如不同）

## 计算检查

- [ ] delta = V3 - V2（方向正确：正数=V3优）
- [ ] AUC delta 计算无误（同客群、同口径）
- [ ] 分桶列对齐（同 decile 的 V2 和 V3 确实对应）
- [ ] 彩色标注方向正确：
  - V3 label 率 > V2 → 绿色
  - V3 label 率 < V2 → 红色
  - 相等 → 不变色

## 结论检查

- [ ] 结论一句话可读（不含技术细节）
- [ ] 结论与数据一致（不说"全面优于"但实际有指标劣化）
- [ ] 缺口清单按优先级排列（P0 → P1 → P2）

## 输出检查

- [ ] JSON 可被正确解析
- [ ] MD 含 5 部分：结论 → AUC对比 → 逐桶对比 → 缺口 → 行动项
- [ ] XLSX 含 2 个 Sheet（AUC对比 + 逐桶对比）
- [ ] XLSX 有颜色标注

## 常见问题速查

| 症状 | 处理 |
|------|------|
| 两个模型客群完全不同 | 分别出报告，不做逐客群对比，只比全量 |
| V3 缺某些客群指标 | 标记为"V3缺失"，不影响其他客群对比 |
| AUC delta 为 None | 至少一方 AUC 为 null，标记而非编造 |
| 分桶数量不一致 | 只对比共有分桶，标记"V2有N桶，V3有M桶" |
