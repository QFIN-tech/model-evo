## 2. 业务概况
用户运营的核心目标是：通过人群圈选、分层、权益、触达、话术和时点优化，提升存量用户的动支、复借、留存和ROI。


## 3. 核心业务链路

> 用户圈选 → 用户分层 → 权益匹配 → 渠道触达 → 用户响应 → 动支 / 复借 / 留存 → 效果回收

| 阶段 | 业务含义 | 重点关注 |
|---|---|---|
| 用户圈选 | 确定可运营用户 | 资格、风险、触达限制 |
| 用户分层 | 按意愿、风险等分层 | 模型分、规则分层 |
| 权益匹配 | 配置优惠权益 | 成本、敏感度 |
| 渠道触达 | Push、短信、外呼等 | 触达率、频控 |
| 用户响应 | 点击、接通、访问、申请 | 响应率、反感率 |
| 目标转化 | 动支、留存 | 转化率、ROI |
| 效果回收 | 评估策略收益 | 实验组、对照组 |

| 任务 | 样本主体 | 标签定义 | 业务用途 |

| 动支意愿模型 | 授信用户 | N天内是否动支 | 动支运营名单排序 |
