## 2. 公司业务概况
- 公司主要面向个人用户提供信贷服务。


## 3. 公司核心业务链路

> 流量获取 → 注册 → 申请 → 授信 → 动支 → 放款 → 还款 → 复借 / 流失

| 阶段 | 业务含义 | 常见建模目标 |
|---|---|---|
| 流量获取 | 通过广告、自然流量等方式获取用户 | 点击率、注册率、申请率预测 |
| 注册 | 用户进入自有用户池 | 注册后转化预测 |
| 申请 | 用户提交借款申请 | 申请意愿、授信通过预测 |
| 授信 | 系统给予额度 | 授信通过、额度、定价 |
| 发起动支 | 用户发起使用额度提款 | 动支意愿发起预测 |
| 动支 | 用户发起使用额度并提款成功 | 动支率预测/提款率预测/放款批核率预测 |
| 还款 | 用户履约还款 | 逾期风险预测、欺诈模型 |
| 复借 | 用户再次借款 | 复借预测、留存预测 |
| 流失 | 用户离开不再借 | 流失预测 |
